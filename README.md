# 🎓 College Discovery Platform

A full-stack web application that helps students discover, compare, and save colleges through an intuitive and data-driven experience.

## 🔗 Live Demo

https://college-discovery-bsve.onrender.com

## ✨ Features

* College listing with search and advanced filtering
* Detailed college profiles with courses, placements, and reviews
* Side-by-side comparison of multiple colleges
* Google Authentication using Auth.js
* Save favorite colleges and comparison sets
* Responsive design for desktop and mobile devices

## 🛠 Tech Stack

* Next.js (App Router)
* TypeScript
* Tailwind CSS
* Prisma ORM
* PostgreSQL (Neon)
* Auth.js (Google OAuth)
* Render

## 🚀 Local Setup

```bash
git clone https://github.com/Gnanendra-kumar/college-discovery.git
cd college-discovery

npm install

cp .env.example .env

npx prisma db push
npm run db:seed

npm run dev
```

## 📂 Project Highlights

* Server-side search, filtering, sorting, and pagination
* Database-backed architecture using Prisma and PostgreSQL
* Type-safe development with TypeScript
* Reusable and scalable component structure
* Production-ready deployment on Render
